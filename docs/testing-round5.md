## 本轮实现

- 新增公共 `wasm_git::trace` API，以及 `trace DIR REV --range START:END` / `--path PATH`。
  起点固定到实际提交 ID；路径只选择起点的物理区间，不按祖先同名路径猜测函数身份。
- 每条父边独立提供完整相关编辑、命中区间、两侧 hex/上下文、未变片段映射、验证状态和诊断。
  替换传播整个旧编辑块的影响；插入的旧侧为空时终止；删除以包含区间两端和 EOF 的边界事件单列。
- 完整父 DAG 在处理共享祖先前收齐到达范围，保持不连续片段的间隙和父列表原有顺序。
  Influence 状态不会在更早的未变片段中降级；根节点只标为快照终点。
- 父边、输入字节比较、范围数和证据记录使用全局预算；相同 blob 对复用比较结果。
  预算耗尽或对齐回退返回明确 frontier 和 `complete=false`，不把未查询历史冒充未变化或起源。
- 仓库新增单锁完整验证快照的祖先图读取，按 blob 对象 ID 去重共享数据。
  无关分支和未引用对象不进入证据图，其损坏仍会使仓库校验失败。

整个报告始终标注 `identity_unproven=true`。完整结果只表示按所选审计脚本与规则遍历完影响范围，
不证明唯一字节来源、函数身份、作者归属或行为等价。用法及详细边界见[历史追踪说明](trace.md)。

追踪单元测试包含一项穷举覆盖检查：31 种短二进制 payload 两侧组合为 961 对，每对查询全文件和末字节，

gap 两侧实际字节相等，父范围非空且合法；删除零长度锚点不被当作当前字节计入覆盖。
这些查询属于上述一个单元测试，不额外计入 226 项测试数。

端到端追踪检查具体物理 span 与 hex，而不仅检查状态字符串，包括：

- 由函数路径及 module 路径选定起点；空 region、非法 ASCII 数值、空/反向/越界范围拒绝。
- 插入后旧内容移位、whole-old 替换范围扩大及其穿过未变祖先后的 Influence 保持。
- 新增字节无旧字节、删除恰落查询起点/终点/EOF、重复内容不声称唯一身份。
- 双父手工解决的完整四条祖先边，以及两条路径到同一祖先的不同范围合流而不填补中间间隙。
- 未知 opcode、不透明 name 约定、合法非规范 LEB 的原始字节历史。
- 单父/双父零预算、全部预算种类及大型 diff 回退的明确停止；停止时不产生虚假根或来源。
- 仓库锁、损坏祖先和无关未引用对象拒绝；查询不改变对象、引用或留下新文件。

另有独立只读复核检查全父拓扑次序、范围合流、删除端点游标、预算失败发布及缓存对应关系，未发现新增实质问题。
