## 本轮实现及边界

- 新增公共 `wasm_git::merge` 三方合并接口，以及仓库 `merge`、`merge-base` 命令。
  快进只更新引用，分叉历史的成功合并保存 `[ours,theirs]` 两个父提交。
- 独立函数修改可组合；同一函数只在局部声明、指令数量和控制骨架满足约束时组合完整指令。
  不拆分立即数字节；合成结果必须通过当前全部已知 feature 的模块验证。
- 未知或无法完整解码的并行修改、索引上下文变化、可识别的搬移和重叠修改返回冲突，
  包含 base/ours/theirs 的物理区间和原始字节；退出码为 2，不写对象或引用。
- 非平凡合并只接受唯一最佳共同祖先；无共同祖先及 criss-cross 的多个最佳祖先明确拒绝。
- 手工解决要求完整目标提交 ID 和 `--expect-head`，防止过期解决文件覆盖已前移的 HEAD。
  保存解决文件的原始字节及双父关系；返回 JSON 披露手工来源和验证状态，未将该快照加入提交格式。
- 整个仓库快照，包括未引用对象及父链，在同一写锁内校验后才产生合并结果并发布引用。

自动组合是受限的结构化操作，不证明行为或开发者意图一致。
搬移检测只覆盖特定的原始字节匹配，不完整识别修改后或重复内容的身份；完整边界见[合并说明](merge.md)。
